# android-portfolio

Portfolio of Android projects, technologies and professional experience.

Senior Android Developer with over 10 years of experience developing native Android applications in Kotlin and Java. My background combines end-to-end delivery for direct clients, from requirements and API integration to app store publication, with enterprise consulting in structured Agile teams.

I specialize in modernizing complex Android applications through Java-to-Kotlin migration, legacy refactoring, Clean Architecture/MVVM, and reusable, modular components, with a focus on code quality and maintainability.

This repository collects selected professional and personal projects. Professional source repositories are generally private because they contain proprietary code owned by companies or clients. Project pages document my contributions without disclosing confidential material.

## Core Skills

- **Native Android:** Kotlin, Java, Android SDK, Views/XML, Custom Views
- **Architecture:** Clean Architecture, MVVM, modularization, reusable components
- **Jetpack:** Jetpack Compose, ViewModel, LiveData, Navigation, Data Binding, Room
- **Asynchronous programming:** Coroutines, Flow (StateFlow, SharedFlow), RxJava
- **Networking and serialization:** Retrofit, Moshi, REST APIs
- **Dependency injection:** Hilt, Dagger
- **Testing:** JUnit, Mockito/MockK, MockServer, Espresso, Jetpack Compose UI Testing
- **CI and development tools:** Azure Pipelines, Git, GitFlow, Gradle
- **AI-assisted Development:** Claude Code (agentic coding workflows), ChatGPT, Gemini, GitHub Copilot
