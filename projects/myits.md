# MyITS

## Role
Mobile Developer — Android / iOS (Freelance/B2B)

## Period
January 2016 – December 2017

## Context
Custom company catalog application with a guided order-creation workflow, developed for a direct client with native implementations for both Android and iOS (Swift).
## Main Contributions
- End-to-end development and delivery of the mobile application
- Development of the native Android application
- Development of the native iOS application in Swift
- Implementation of company catalog browsing
- Development of the order creation wizard
- Integration with backend REST APIs and JSON-based services
- Testing, release and maintenance activities
- Publication support for Google Play and Apple App Store
