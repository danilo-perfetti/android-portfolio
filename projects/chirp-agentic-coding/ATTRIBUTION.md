Course reference:

**Building Industry-Level Compose Multiplatform Android & iOS Apps**  
PL Coding / Philipp Lackner  
https://www.pl-coding.com/courses/cmp-mobile

## What This Portfolio Publishes

This public portfolio entry contains only:

- a description of the experiment;
- engineering methodology;
- architecture notes;
- testing and accessibility findings;
- AI-agent workflow and guardrail concepts.

It does **not** publish:

- the course source code;
- the private experiment source repository;
- course-only Figma assets;
- private course documents;
- internal credentials or configuration.

## Independent Experiment Work

The agentic-coding experiment introduced work that was separate from simply following the course implementation, including:

- isolated blind implementation workflow;
- Claude Code integration and project guardrails;
- Figma Remote MCP workflow;
- independent Gemini review;
- human-in-the-loop review process;
- delayed reference comparison;
- security/logging hardening;
- post-experiment automated testing;
- Ktor MockEngine integration;
- shared Compose UI testing;
- semantics/accessibility hardening;
- Android TalkBack validation;
- iOS accessibility gap assessment.

This attribution is intended to clearly distinguish the original project/course context from the independent engineering experiment documented in this portfolio.
